## 阶段 5A：元认知 ⚠️ 部分成功

**目标**：让模型知道自己什么时候不确定。

**方法**：在 WorldModel 上加置信度头，训练时同时预测”这一 token 我猜对了吗“。

**结果**：

| 场景 | acc | ECE |
|---|---:|---:|
| 训练分布（32 步，教师强制） | 0.9575 | 0.0063 |
| 全新世界（单步） | 0.9331 | 0.0199 |

**ECE 极低，但只在 in-distribution 成立。**

**Rollout 测试**（关键验证）：

| rollout 步数 | 真实 acc | 平均置信度 |
|---|---:|---:|
| 1 | 0.9531 | 0.9549 |
| 5 | 0.5469 | 0.9546 |
| 20 | 0.2656 | 0.9561 |
| 50 | 0.1250 | 0.9541 |

**真实准确率跌 80 个点，置信度几乎不变——严重过度自信。**

**MC Dropout 交叉验证**：in-distribution 方差 0.427，rollout 30 步 0.383，无显著区分。

**结论**：
- 确定性小型模型（1.45M 参数）天生没有可靠的元认知机制
- 置信度头学的是”训练分布下的平均准确率“，无法应对分布偏移
- MC Dropout 测的是参数敏感性，不是认知不确定性
- 要实现真元认知，需要深 ensemble 或贝叶斯权重——超出当前规模

**下一步**：跳过基于置信度的元认知，转向阶段 5B：基于训练 loss 的惊讶采样。
